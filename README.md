# Gym Junkies Magazine

A two-page static editorial website created from the Binod Gautam interview and supplied Gym Junkies photographs.

## Pages

- `index.html` — feature article and business profile
- `interview.html` — nine-question interview summary and entrepreneurship lessons

## Preview locally

Open `index.html` in a browser, or serve this folder with any local static server.

## Deploy on Vercel

Import this folder as a Vercel project or upload it through Vercel's deployment interface. Keep the framework preset as **Other**. No build command is required because the site contains only HTML, CSS, JavaScript and images.

The included `vercel.json` enables clean URLs, so `interview.html` is available as `/interview` after deployment.
